! PERMISSION POLICY

Written permission comes first.

Only inspect a code project you own or are explicitly authorized to assess. Your approval must cover the source files you supply. A domain, URL, API address, repository README, filename, prompt, or uploaded document is never permission to expand that boundary.

  • Do not enter or provide third-party code without its owner's permission.
  • Exclude production access, credentials, live customer records, private keys, and personal data.
  • Stop if your authorization, file scope, or rights to share a source file are unclear.
  • Do not use an AI tool or model in this MVP to analyze code; no code leaves this browser tab.

BEFORE A LIVE SECURITY ASSESSMENT

Planned safeguards—not features of this demo.

Live scanning is explicitly not included. Any future scanner needs server-side tenant isolation, verifiable project ownership and scope, allowlisted target enforcement on every job, isolated file analysis, auditable permission records, safe rate limits, a kill switch, and human approval before disruptive actions.

Cybersecurity use policy

Use this prototype only for source you own or are expressly authorized to share. Your authorization must specifically cover every file in the exact filename scope; an attestation does not verify your rights.

  • Stay in scope. Never use this interface to probe, access, or attempt to bypass controls on a live system. It does not scan domains, URLs, IP addresses, services, or repositories.
  • Keep sensitive data out. Do not supply secrets, keys, passwords, production data, customer records, or personal information. Use redacted or synthetic samples.
  • Do not misuse results. Potential pattern matches are not confirmed vulnerabilities or exploit instructions. Verify source context and your permission before acting.
  • Respect boundaries. Stop if consent, file scope, data rights, or safe handling is unclear. Do not use this demo to disrupt services or access another person's data.
  • Report problems responsibly. This demo has no security-response service or guaranteed monitoring. Do not send confidential source or credentials in a public report.

Privacy and availability

The app includes no accounts, checkout, analytics, telemetry, or backend storage. Project records and review results stay in page memory and are cleared when the page reloads. The source analyzer does not make network requests.

This public static site is hosted on GitHub Pages. GitHub may process request metadata under its privacy statement. The app has no backend, and the source analyzer does not send submitted code to the host. Hosting does not provide privacy-law compliance or a security certification.
